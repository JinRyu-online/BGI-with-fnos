## 方案
现在我搞定了WOL和AUTOLOGON两部分，关于开机后制定执行bettergi脚本我有个方案：
- 我有一个局域网的飞牛NAS，可以通过暴露端口的方式，让NAS走网络请求来触发脚本执行，这样最不会对日常使用造成影响，也能更好的控制


## 大体实现方案：
#### NAS网络触发
这个方案的核心是将电脑变成一个“服务端”，NAS作为“客户端”发送执行指令。你需要解决“如何让NAS安全地发消息”和“如何让Windows接收消息并执行”两个问题。

大体实现路径
```
flowchart LR
    A[NAS发送HTTP请求/SSH命令] --> B[Windows端监听服务]
    B --> C[验证请求合法性]
    C -- 验证通过 --> D[执行启动BetterGI脚本]
    C -- 验证失败 --> E[拒绝执行]
    D --> F[脚本执行完毕后<br>可自动关机/休眠]
```
